# CircuitForge

The application lives in [circuit-forge](circuit-forge/README.md). Open that folder in VS Code.

```sh
cd circuit-forge
npm ci
npm run dev
```

Open http://127.0.0.1:5173. See the [application README](circuit-forge/README.md) for features, tests, evidence, and limits.
